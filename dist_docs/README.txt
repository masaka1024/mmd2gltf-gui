■ これは何?
----------------------------------------------------------------
MMDのPMXモデル(+VMDモーション)を、できる限り忠実に
glTF 2.0形式(.glb)へ変換するツールです。

・Pythonのインストールは不要。EXEをダブルクリックするだけで
  GUIが起動します。
・変換した.glbは、Webビュアー・Blender・Unity等の
  glTF対応環境でそのまま読み込めます。
・髪やスカートの揺れをアニメーションとして焼き込む
  「物理ベイク」機能も搭載しています(任意)。


■ 動作環境
----------------------------------------------------------------
・Windows 10 / 11 (64bit)
・追加のインストールは不要です。
  (Pillow / NumPy / tkinterdnd2 等は同梱済み)

■ はじめかた(3ステップ)
----------------------------------------------------------------
  1. mmd2gltf.exe をダブルクリックして起動
  2. PMXファイル(必要ならVMDも)を指定
     ※エクスプローラーからのドラッグ&ドロップにも対応
  3. 「変換」を押して、出力された .glb をビュアーで確認

詳しい手順やオプションの意味は「使い方説明書.txt」を
ご覧ください。


■ 初回起動時の警告について(重要)
----------------------------------------------------------------
署名を付けていない個人開発ソフトのため、初回起動時に
Windows SmartScreenが

  「WindowsによってPCが保護されました」

と表示することがあります。その場合は
「詳細情報」→「実行」の順にクリックすると起動できます。

また、ウイルス対策ソフトがPyInstaller製のEXEを誤検知する
場合があります。ソースコードは上記GitHubリポジトリで
すべて公開していますので、気になる方はご確認ください。


■ 変換後モデルの取り扱いについて(必ずお読みください)
----------------------------------------------------------------
変換後のモデルは、元のモデル・モーションの利用規約に
従います。

本ツールはPMX/VMDファイルの形式変換のみを行うもので、
変換元の著作権や利用条件には一切関与しません。
変換したモデルを配布・利用する際は、必ず元モデルの規約
(改変可否、二次配布可否、クレジット表記義務など)を確認し、
それに従ってください。

■ 変更履歴
----------------------------------------------------------------
v1.3.0
  ・しっぽやベルトを腰などへ繋ぎ直す「吊り」ジョイントを持つモデルで、
    揺れ物の鎖の親子関係が末端で逆転していた問題を修正しました。
    書き出し先(UE5等)で鎖が伸びて床まで垂れる症状が出ていました。
  ・移動できないボーン(移動可フラグの無いボーン)へVMDの移動値が
    適用されていた問題を修正し、MMDと同じ扱いにしました。
    物理焼き込み系ツールが書き出した「フルキー」VMDで影響が出ます。
    該当したボーンは変換ログに一覧で表示されます。
  ・extras.mmd にボーン一覧(bones)を追加しました。読み込み側が
    「移動可能なボーンか」等を仕様どおり判定できます。
  ・日本語環境のコンソールで、物理ベイクがログ出力の文字化けを
    きっかけに中断していた問題を修正しました(コマンドライン版のみ。
    GUIは元から影響を受けません)。

v1.2.0 以前の変更点は GitHub のリリースページをご覧ください。
  https://github.com/masaka1024/mmd2gltf-gui/releases
